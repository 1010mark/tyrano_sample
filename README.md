# おまけ：湯けむりの隠れ家からの脱出（`docs/yukemuri/`）

作者が所属するサークルの合宿で出した謎解きを、ティラノスクリプトで遊べるように移植したものです。合宿の謎解き企画に乱入してきた『湯けむりの隠れ家』を名乗る人物から、制限時間60分で脱出を目指します。

* [プレイする](https://1010mark.github.io/tyrano_sample/yukemuri/)

## 遊び方

* クリックで会話を進めます。オープニングは右上の「スキップ」で飛ばせます。
* STEP1 はキットの問題を解いてパスワードを入力し、STEP2 からは「対消滅システム」（ものの名前を書き並べて、同じ文字を消すシステム）を使って事件の解決を目指します。
* 困ったときはメニューの「ヒント」を開いてください。結果のあとに解説編を見られます。
