# 湯けむりの隠れ家からの脱出

## 概要

ティラノスクリプトで作った、ブラウザで遊べる謎解きゲームです。合宿の謎解き企画に乱入してきた『湯けむりの隠れ家』を名乗る人物から、制限時間60分で脱出を目指します。

* [プレイする](https://1010mark.github.io/tyrano_sample/)

## 遊び方

* クリックで会話を進めます。オープニングは右上の「スキップ」で飛ばせます。
* STEP1 はキットの問題を解いてパスワードを入力し、STEP2 からは「対消滅システム」（ものの名前を書き並べて、同じ文字を消すシステム）を使って事件の解決を目指します。
* 困ったときはメニューの「ヒント」を開いてください。結果のあとに解説編を見られます。

## ファイル

* `docs/data/scenario/` … シナリオ（`first.ks` から始まる）
* `docs/data/others/qpc/` … ゲームの処理（対消滅システムの判定・メニュー・タイマーなど）
* `docs/data/image/qpc/` … キット・シート・スライドの画像
